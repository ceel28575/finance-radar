# MX 采集与云端同步

1. 安装时运行 `setup.bat`（已安装的依赖可复用）。
2. 在私有网站的「采集与设置」下载 `cloud-config.json`，放在本目录，不要改名。
3. 关闭旧采集器及它打开的浏览器后，运行 `start.bat`。在程序打开的 MX 网页手动登录。登录会话仅保存于本机 `mx_profile`。
4. 每 60 秒导出本机 SQLite 资料，并同步新增/变更记录到私有网站；网络失败下次重试。本机无配置时仅导出，正常采集不受影响。
5. 同步成功会显示资讯及 AI 报告上传数量。网站每 60 秒读取云端，可在「采集与设置」检查最近同步时间与各日记录数。
6. 启动采集器时会隐藏提示输入豆包 API Key；也可在启动进程前设置 `ARK_API_KEY` 环境变量。程序启动时会先用实际生产接口、模型名和同一 HTTPS 传输方式做一次短请求验证，验证成功后才启动 AI worker；密钥只保存在本次进程内存，不写入配置文件、日志或 GitHub。不要把密钥发给任何人。
7. 双模型分析自动运行：本地 Ollama `qwen3.5:4b` 负责资讯分类、摘要、公司名称和事实提取；豆包 `doubao-seed-evolving` 负责指数多空概率、盘面总结、风险及有来源依据的候选股。Ollama 需在本机运行，模型可用 `OLLAMA_MODEL` 覆盖。
8. A 股交易时段每 60 秒分析，11:30–13:00 午休跳过；15:10 后及非交易时段每 30 分钟检查。收盘后生成下一交易日股票池并冻结，盘中报告沿用当天固定股票池。周末的下一交易日按周一处理；未接入交易所节假日日历，节假日需人工核对。

如用新文件夹升级，可在旧程序完全退出后，将旧目录的 `mx_profile`、`mx_outbox.db` 复制到新版同名目录，以保留会话和历史。不要上传这些文件。

## 当前边界
- 同步频率是 60 秒；扫描大量房间或回溯历史可能超过 60 秒，不能保证每个房间一分钟内全部刷新。
- 同名房间尚未取得稳定 ID，跳过并报告，避免串房。日期仅为时分的消息使用原采集器推算规则，网页标注待核实。
- 图片链接保留；图片 OCR 尚未接入。含文字的图文消息可先分析文字，纯图片不作为已识别证据。
- 双模型 AI 已加入采集器：本地 Qwen 预处理、云端 Doubao 生成研判；报告随云端同步上传。AI 运行失败不会停止 MX 采集与原始数据同步。
- 盘中报告可随新证据更新；每日股票池在收盘后建立并冻结，供下一交易日使用。若收盘时证据不足，允许形成空池，不把无依据股票塞入池中。模型报告必须提供原文 ID 作为证据，证据不足的股票不进入股票池。指数多空概率是主观情景判断，不是统计胜率。
- 云端按带时区时间换算北京时间日期，相同 ID 更新；屏蔽奇幻团课/qmxp2077。
- 配置含私有网站访问凭据，只用于你自己的电脑。程序仅向固定项目网址发送，禁止重定向。无需提供 MX 密码给网站。
- `mx_cloud.db` 只记录成功接收的内容指纹。失败数据仍在本地；不将失败上传标为成功。
