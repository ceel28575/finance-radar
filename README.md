# 财经雷达

中文财经研究工作台。直接打开 index.html 即可使用；无第三方脚本依赖。

## 已实现
- 市场总览、日期筛选、双列股票池、评分排序、收藏。
- 股票证据、催化、风险、失效条件、观点变化展示。
- 资讯全文搜索、来源和时间追溯、历史报告。
- JSON 导入校验、去重、推广来源过滤、每日导出。
- 响应式布局、HTML 转义、本机持久化。

## 当前边界
这是可使用的前端首版，MX 自动采集、OCR、GPT 分析、云端数据库及后台调度尚未接通。页面没有模拟市场数据。资料保存在当前浏览器 localStorage，不跨设备同步。导出 JSON 可备份。

## 导入格式
在「采集与设置」点击「查看导入格式」。顶层包含 items 和 reports 数组。资讯时间必须包含时区，按北京时间归档。股票只显示名称，不提供代码。

## 接入目标
后端需提供安全身份校验、加密配置、资讯去重入库、图片 OCR、带证据的 AI 分析和日内股票池版本。调度目标为 A 股盘中每 3 分钟、盘后每 30 分钟、午休跳过，需交易日历。GitHub Pages 只能运行前端，不能执行这些后端任务。

## 凭据
本仓库不包含 MX 密码、会话或模型密钥。不要把这些内容放入前端、导入文件或公开仓库。
